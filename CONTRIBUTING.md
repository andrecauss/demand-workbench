# Contribuição

Este repositório é atualmente uma base de produto e arquitetura. Antes de adicionar implementação, abra ou atualize os documentos relevantes de requisito, domínio, regra de negócio, modelo de dados, arquitetura e ADR.

Não transforme um item em aberto em código por suposição. Marque com clareza as decisões propostas, solicite revisão para mudanças transversais e inclua testes, considerações de segurança e documentação em cada incremento de implementação.
