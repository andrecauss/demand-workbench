# Planning Unit Supersession

Supersession representa uma relação de negócio na qual uma Planning Unit substitui outra. O repositório reserva esse conceito para uso futuro, mas o FRS não define seu comportamento no MVP.

Antes da implementação, é necessário definir datas de vigência, relações um-para-um ou muitos-para-muitos, tratamento da demanda histórica, efeito sobre Forecast Versions abertas e requisitos de auditoria.
