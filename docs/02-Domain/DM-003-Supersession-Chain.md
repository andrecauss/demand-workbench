# Supersession Chain

Uma Supersession Chain é um conjunto ordenado de relações de Planning Unit Supersession. Ela pode ser necessária para preservar a continuidade analítica quando produtos são substituídos.

Nenhum cálculo de cadeia, regra de agregação ou critério de aceite do MVP foi aprovado. Mantenha esse conceito fora dos cálculos de Forecast até que o ADR de supersession seja aprovado.
