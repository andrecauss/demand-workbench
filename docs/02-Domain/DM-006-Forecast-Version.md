# Forecast Version

Uma Forecast Version é um conjunto governado de resultados de previsão de um Planning Cycle. Seus estados são Draft, Under Review, Approved e Published.

Somente uma versão pode estar Published por ciclo. Criação, revisão, aprovação, publicação e alterações relevantes devem gerar informações de auditoria. Papéis, reabertura e comportamento de reversão ainda são decisões em aberto.
