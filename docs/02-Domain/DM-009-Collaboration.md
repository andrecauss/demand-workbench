# Collaboration

Collaboration é a atividade de revisar e contribuir em uma Forecast Version antes da publicação. O produto prevê um Collaboration Workbench, mas ainda não define comentários, atribuições, aprovações, notificações ou resolução de conflitos.

O mínimo do MVP é a revisão governada por estados de versão e auditoria. Uma colaboração mais rica exige especificação funcional separada.
