# Tag

Uma Tag é um metadado informativo anexado a entidades relevantes de planejamento. Exemplos do FRS são Export, Warranty, Recall e New Model.

Tags não devem alterar a elegibilidade de Forecast nem os cálculos, exceto quando uma regra de negócio aprovada definir esse efeito explicitamente. Responsável, valores permitidos e ciclo de vida ainda precisam ser definidos.
