# Forecast Classification

Forecast Classification determina como um item participa do planejamento:

- `Forecastable`: elegível ao processamento de Forecast.
- `Non-Forecastable`: não elegível ao processamento de Forecast.
- `No Classification`: ainda não recebeu classificação.

O responsável pelo negócio deve definir o comportamento para itens sem classificação, quem pode alterá-la, quando as mudanças entram em vigor e como são auditadas.
