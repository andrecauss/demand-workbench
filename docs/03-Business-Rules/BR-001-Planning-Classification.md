# BR-001 — Planning Classification

Somente Planning Units classificadas como `Forecastable` fazem parte da população confirmada de previsão do MVP. Itens `Non-Forecastable` não devem receber a saída padrão de Forecast. `No Classification` exige política operacional explícita antes do processamento.

Mudanças de classificação devem registrar ator, data e hora, data de vigência, valor anterior e novo valor.
