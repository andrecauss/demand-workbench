# MOD-003 — Publish Workbench

O Publish Workbench autoriza a Publication de uma Forecast Version Approved, garante uma única versão Published por Planning Cycle, registra informações de auditoria e produz as exportações iniciais para Excel e Access.

Ele deve expor metadados suficientes para identificar versão, ciclo, ator, data e hora e resultado da exportação. O layout, destino e mecanismo de entrega da exportação exigem aprovação específica.
