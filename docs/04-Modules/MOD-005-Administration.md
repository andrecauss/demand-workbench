# MOD-005 — Administração

Administração gerencia a configuração controlada necessária ao workbench: master data de Planning Unit, classificação, Tags, configurações de modelo, horizonte padrão, papéis e dados de referência.

O FRS não define telas administrativas, responsáveis ou modelo de permissões. Apenas papéis aprovados podem alterar controles que mudem a elegibilidade de Forecast, o comportamento do modelo ou a autoridade de Publication.
