# FR-002 — Ajustes de negócio e governança de versões

O sistema deve suportar Previous Forecast Switch, Trend Overrides e Forecast Offset depois que suas semânticas de negócio forem aprovadas. Deve preservar Forecasts base e ajustados, além de auditar ator, data e hora, justificativa e regra aplicada.

O sistema deve gerenciar Forecast Versions nos estados Draft, Under Review, Approved e Published, autorizar transições e garantir uma versão Published por Planning Cycle.
