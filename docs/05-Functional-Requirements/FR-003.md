# FR-003 — Publication, auditoria e exportação

O sistema deve registrar informações de criação, aprovação e Publication de uma Forecast Version. A Publication deve identificar a versão oficial de seu Planning Cycle e preservar metadados suficientes para reproduzir o resultado publicado.

O sistema deve suportar exportações iniciais para Excel e Access. Esquemas, entrega, segurança e critérios de aceite precisam ser especificados antes da implementação.
