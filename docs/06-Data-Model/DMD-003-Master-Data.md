# DMD-003 — Master Data

Os dados de referência necessários incluem Segment, Market, Sector, Family, SKU, Customer Type e Customer, além de Planning Classification, Tag, configuração de modelo, papel e dados de referência de Planning Cycle.

Cada sistema-fonte, responsável de negócio, Business Key, política de vigência, regra de qualidade e processo de alteração deve ser definido antes da integração.
