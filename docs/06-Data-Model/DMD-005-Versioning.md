# DMD-005 — Versionamento

Forecast Versions são registros com estado dentro de um Planning Cycle. Uma versão Published é o snapshot oficial e imutável daquele ciclo.

Na camada de armazenamento, garanta uma única versão Published por Planning Cycle. Registre linhagem da versão, data e hora das transições, atores e conjunto de Forecast Results contidos na versão.
