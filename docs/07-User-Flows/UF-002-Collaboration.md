# UF-002 — Collaboration

1. Um usuário autorizado envia uma Forecast Version Draft para Under Review.
2. Revisores inspecionam Forecasts, métricas, dados históricos e ajustes registrados.
3. O resultado da revisão move a versão conforme a política aprovada de transição de estado.
4. Uma versão Approved torna-se elegível para Publication.

O FRS ainda não define comentários, tarefas, notificações, rejeição ou comportamento de retrabalho.
