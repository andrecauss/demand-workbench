# ARC-005 — Segurança

O sistema deve proteger dados de planejamento e assegurar que alterações de Forecast e Publication sejam autorizadas e auditáveis. Controles centrais incluem autorização baseada em papéis, tratamento seguro de segredos, criptografia, integridade de auditoria, varredura de dependências e segredos, higiene de logs e backup e recuperação testados.

Consulte a [Base de segurança](../00-Handoff/SECURITY-BASELINE.md) para os gates atuais. Não é possível fazer revisão de segurança da implementação até existirem código e infraestrutura.
