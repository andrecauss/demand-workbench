# ARC-006 — Estratégia de versionamento

Forecast Version é o limite de governança de negócio; Publication produz o snapshot oficial e imutável de um Planning Cycle. A aplicação deve manter o histórico de estados e garantir uma versão Published por ciclo de forma transacional.

A reprodutibilidade de dados e modelos exige identificadores imutáveis para snapshots de entrada, versões de modelo, parâmetros, tratamentos, ajustes e exportações. A estratégia detalhada de retenção e correção exige aprovação.
