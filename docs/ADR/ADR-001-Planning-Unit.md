# ADR-001 Planning Unit

## Status

Proposto — decisão necessária.

## Contexto

A Planning Unit é a menor entidade de manutenção de Forecast. O FRS lista os níveis de planejamento, mas não define a chave nem a hierarquia.

## Decisão necessária

Aprovar a composição, a Business Key, a propriedade do master data, as datas de vigência e a relação com a granularidade de Forecast. Nenhuma decisão de implementação foi tomada.
