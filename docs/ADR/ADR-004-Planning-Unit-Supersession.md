# ADR-004 Planning Unit Supersession

## Status

Adiado.

## Contexto

Os conceitos de supersession existem na estrutura de documentação, mas não no escopo confirmado do FRS.

## Decisão

Não implementar o comportamento de supersession no MVP. Reavaliar somente com regras de linhagem, datas de vigência, transferência de histórico, versões abertas e auditoria.
