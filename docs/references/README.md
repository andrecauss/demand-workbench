# Referências

## Demand Workbench Functional Requirements Specification v1.0

[`Demand_Workbench_FRS_v1.0.docx`](Demand_Workbench_FRS_v1.0.docx) é a referência original de requisitos funcionais fornecida com este projeto. Seu conteúdo foi consolidado nos documentos de overview, domínio, regra de negócio, requisito funcional, modelo de dados, arquitetura, roadmap, ADR e handoff.

Os documentos em Markdown são mais fáceis de revisar e evoluir no Git; o DOCX é mantido como artefato-fonte para rastreabilidade. Quando uma decisão futura aprovada divergir do DOCX, registre essa decisão no documento correspondente e no ADR.
